# 仮想ホスティング

仮想ホスティングとは、１つのIPアドレスに複数のサイトを紐づけるホスティング方法。  

- `www.example.com`
- `www.company.jp`

この２つのサイトを同じWEBサーバー上に構築する。

## 仕組み

WebブラウザのURL窓に`www.example.com`を入力する。  
WebブラウザはDNSサーバーへドメインを問い合わせてIPアドレスを取得する。  
結果、Webブラウザは`http://x.x.x.x`というURLを用いてHTTPリクエストを送る。その際に、Hostヘッダにアクセス先のドメイン名を通知する。

```HTTP
GET / HTTP/1.1
Host: www.example.com
```

サーバーはこのHostヘッダを確認し、自身のサーバーでホスティングしているドメインへルーティングする処理を行う。

## 利点

この仮想ホスティングとIPベースホスティングと違いだが、IPベースホスティングの場合はIPアドレスが2つ必要になる。

|IPアドレス|ドメイン|
|:--|:--|
|x.x.x.x|`www.example.com`|
|y.y.y.y|`www.company.jp`|

IPv4を節約するためにも同一IPアドレスでN個のドメインをホスティングしたい。

## Apache

Apacheだとこんな感じの設定を書く。

```conf
<VirtualHost *:80>
    ServerName www.example.com
    DocumentRoot /var/www/example
</VirtualHost>

<VirtualHost *:80>
    ServerName www.company.jp
    DocumentRoot /var/www/company
</VirtualHost>
```

## Nginxだと

Nginxだとこんな感じの設定を書く。

```conf
server {
    listen 80;
    server_name www.example.com;

    root /var/www/example;
    index index.html;
}

server {
    listen 80;
    server_name www.company.jp;

    root /var/www/company;
    index index.html;
}
```
